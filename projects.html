Tạo dự án mới thế nào?1 dự án = 1 branch

  1. Mở phiên Arena mới cho dự án mới → Arena tự tạo branch arena/<id> cho phiên đó.
  2. Hoặc tạo branch ngay trong máy: npm run project:new -- "Tên dự án" --type game
  3. Mỗi dự án nằm ở một thư mục riêng, entry tĩnh (index.html) để mở/preview độc lập.
  4. Merge xong thì xoá branch, hoặc giữ lại nếu muốn tiếp tục phát triển dự án đó.
npm run project:new -- "Game bắn máy bay" --type game   # tạo branch + khung dự án
